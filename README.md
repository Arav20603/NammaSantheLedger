# Namma Santhe Ledger

An Android-based digital ledger application designed for small-scale vendors and local market businesses to manage customer transactions, track balances, and maintain financial records efficiently.

---

## 📱 Project Overview

Namma Santhe Ledger is a mobile application developed to simplify day-to-day ledger management for local vendors and small businesses. The application helps users maintain customer records, track credit/debit transactions, and manage outstanding balances digitally instead of relying on traditional handwritten notebooks.

The app aims to support organized bookkeeping, improve transparency in transactions, and reduce the chances of manual calculation errors.

---

## ✨ Features

* ➕ Add and manage customer details
* 💰 Record credit and debit transactions
* 📒 Maintain digital ledger entries
* 🔍 Search and filter customer records
* 📊 Track pending balances and payment history
* 📱 Simple and user-friendly Android interface
* 🔐 Local data storage for secure record keeping

## 🚀 Installation & Setup

### Prerequisites

Make sure you have the following installed:

* Android Studio
* Android SDK
* Git
* Kotlin support enabled

### Clone the Repository

```bash
git clone https://github.com/Arav20603/NammaSantheLedger.git
```

### Open in Android Studio

1. Open Android Studio
2. Click on **Open Project**
3. Select the cloned repository folder
4. Sync Gradle files
5. Run the application on an emulator or Android device
